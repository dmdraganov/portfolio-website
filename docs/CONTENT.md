# Публичные тексты портфолио

Канонический публичный текст хранится в типизированных файлах:

- `src/content/site.ts` — метаданные главной, навигация, контакты, главная
  страница, общая UI-лексика, 404 и подписи Case Study;
- `src/content/projects.ts` — карточки и полные тексты проектов, ссылки,
  metadata и подписи изображений.

Этот документ больше не дублирует текст сайта. Редакционное согласование
происходит по diff канонических TypeScript-файлов. Компоненты не должны
содержать утверждаемую публичную копию и не должны изменять её при рендеринге.

Изменение коммерческих условий, позиционирования, проектных утверждений,
контактных адресов или CTA требует отдельного содержательного ревью.
