# Personal Portfolio Website

Личный сайт-портфолио Дмитрия Драганова для презентации услуг веб-разработки и привлечения фриланс-клиентов.

## Stack

- Next.js
- Tailwind CSS
- Motion
- Prettier
- ESLint
- shadcn/ui
